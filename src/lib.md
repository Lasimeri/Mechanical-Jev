# lib.rs: the crate

TypeSafe's Jev from Rust, the client side only. [`protocol`](protocol.md)
has the wire types and a request builder; [`client`](client.md) calls the
API; [`confidence`](confidence.md) has TypeSafe's confidence formulas;
[`eval`](eval.md) scores labelled case files with Jev;
[`corroborate`](corroborate.md) compares two recorded runs;
[`config`](config.md) reads the key and defaults from files.
